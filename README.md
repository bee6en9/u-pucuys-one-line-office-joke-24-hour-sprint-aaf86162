[One-Line Office Joke: 24-Hour Sprint on make.fun](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162)

A deterministic Node program that writes a single one-line joke about office
life (at most 200 characters) to `/output/entry.txt`.

The joke: a concrete office scene — when the office plant dies, HR treats it
with full corporate seriousness: a condolence email, then a meeting to
interview its replacement.

## Run

```sh
node main.ts
```

Then check `/output/entry.txt` (one line, 1–200 characters).
